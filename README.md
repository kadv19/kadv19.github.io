# Advaith — portfolio (prototype)

React + Vite + Tailwind v4 + GSAP/ScrollTrigger. The character is a procedural SVG rig (`src/character`).

```
npm install
npm run dev     # site at /, design system + character lab at /#lab
npm run build
```

Edit your content in `src/data/content.ts`. Read `docs/STRATEGY.md` first.
