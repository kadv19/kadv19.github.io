Safety-Net Guardian

DevOps Observability Pipeline

Docker · Kubernetes · Argo Rollouts · Prometheus · Grafana · CI/CD

Overview

A full CI/CD pipeline with live canary deployments and real-time observability, deliberately demoed under real network constraints rather than a sanitized local environment.

Problem

Most student DevOps projects are demoed on localhost with no real deployment risk. I wanted to prove the pipeline actually worked the way production systems do - safe, gradual rollouts, visible in real time, accessible from outside a local machine.

Architecture

Code push to CI pipeline to Kubernetes deployment via Argo Rollouts (canary strategy) to Prometheus scraping metrics to Grafana dashboards, all tunneled live via ngrok for the faculty demo.

Technical Deep-Dive

Argo Rollouts manages progressive canary deployment - a new version receives a small percentage of traffic first, and rollout continues only if health metrics stay green. Prometheus scrapes real-time metrics from the running pods; Grafana visualizes rollout health, error rates, and latency live during the demo. Entire stack containerized with Docker, orchestrated via Kubernetes. Chose ngrok tunneling specifically so the demo reflected real network latency and exposure rather than a local-only walkthrough.

Challenges

Configuring canary rollout thresholds that were sensitive enough to catch real issues without being triggered by normal noise. Making the observability dashboards genuinely legible in a live demo setting, not just functional in isolation.

My Role

Built with teammate Arun V - shared ownership of pipeline design, deployment strategy, and monitoring setup.

Results

Successful live demo to faculty showing real canary rollout behavior and real-time metrics, accessible over the public internet via ngrok.
