AI Ghost

On-Device Memory Resurrection System

Android · Python · FastAPI · AWS S3 · Gemma 3 (1B INT4) · MediaPipe · sentence-transformers

github.com/kadv19/AiGhost ↗

Overview

A privacy-first two-app Android system that lets you conversationally query your old phone's data from your new device — with zero cloud AI involved.

Problem

Every 2-3 years, billions of people migrate to a new phone. Existing solutions (Google Drive, cloud backups) move files but can't answer questions about them. There's no way to ask "when's my exam?" or "what was that address my friend sent me?" without manually digging through old apps.

Architecture

Extractor app (old phone) processes local data, generates embeddings, uploads to AWS S3. Retrieval app (new phone) downloads processed data, runs on-device RAG, serves conversational answers. S3 acts as the async message bus connecting the two — no server, no socket connection, no shared backend required.

Technical Deep-Dive

Python backend generates 384-dimensional embeddings via sentence-transformers. On-device cosine similarity search retrieves top-5 relevant chunks in under 50ms. Gemma 3 1B (INT4 quantized) runs fully offline via MediaPipe's LLM Inference API — streaming token generation, zero OpenAI/cloud dependency.

Ghost Key authentication: a 4-word passphrase is baked directly into the S3 object path structure. No auth server, no database, no session management — the path itself is the credential. Presigned URL feature: users can request a specific file by name and receive a 1-hour expiry download link, bridging conversational retrieval with actual file delivery.

Challenges

Getting a 1B-parameter model to run smoothly on-device without frying battery or thermal-throttling. Designing authentication that required zero backend infrastructure while staying secure. Keeping retrieval latency under 50ms despite running entirely on-device.

My Role

Results

169 memory chunks indexed and retrievable in the working demo. Fully offline after initial setup. Zero cloud AI cost.
