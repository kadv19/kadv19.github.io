Deepfake Detection via Physiological Signal Analysis

Python · FastAPI · OpenCV · SciPy · Scikit-learn

Overview

A deepfake detector that doesn't look at pixels — it looks at your heartbeat.

Problem

Most deepfake detectors chase visual artifacts (blending edges, flickering, unnatural blinking) — an arms race the generative models keep winning. A more fundamental signal was needed: something hard to fake because the forger doesn't even know it exists.

Architecture

Video input → frame extraction → Eulerian Video Magnification → PPG signal extraction → classifier → confidence score, served via FastAPI.

Technical Deep-Dive

Implemented Eulerian Video Magnification (EVM) in Python to amplify sub-pixel skin-color shifts correlated with heartbeat (photoplethysmography / PPG) — signals invisible to the human eye but physiologically present in real footage. Real faces show consistent, physiologically plausible PPG signals; most deepfakes either lack this signal entirely or show inconsistent/impossible patterns.

Trained and evaluated a Scikit-learn classifier on 150+ videos from the FaceForensics++ dataset — achieved 85% detection accuracy. Exposed via a stateless FastAPI REST service, <30s processing time per video. Added result caching, cutting disk I/O by 60%.

Challenges

PPG signals are extremely subtle — amplifying them without amplifying noise was the core signal-processing problem. Balancing processing speed against detection accuracy for a usable API response time.

My Role

Solo project — designed the signal processing pipeline, trained the classifier, built and optimized the API.

Results

85% accuracy on 150+ test videos, sub-30-second inference, extensible architecture for healthcare monitoring and biometric authentication use cases.
