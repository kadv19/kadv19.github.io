NutriMind

AI Food Health Advisor

Gemini 1.5 Flash Vision API · Firebase · React · FastAPI · Google Cloud Run

AMD Ideathon, REVA University

Overview

An AI food advisor that gives goal-aligned nutrition guidance, not generic calorie counts, built end-to-end in a single hackathon sprint.

Problem

Most nutrition apps treat every user the same - same calorie targets, same generic advice. Someone managing diabetes, someone on a tight budget, and someone trying to gain muscle need fundamentally different guidance from the exact same plate of food.

Architecture

Photo upload to Gemini 1.5 Flash Vision API (food identification) to goal-matching logic to personalized recommendation, with Firebase handling auth/history and React/FastAPI powering the app.

Technical Deep-Dive

User sets goals at onboarding: weight loss, muscle gain, diabetes management, budget constraints. Gemini Vision identifies food from a photo; backend cross-references identified food against the user's specific goal profile. Recommendations are goal-relative - the same plate of biryani gets different advice for a muscle-gain user vs. a diabetes-management user. Full stack built and deployed within the hackathon window: authentication, food logging, AI analysis, and history - all functional end-to-end.

Challenges

Designing goal-aware recommendation logic (not just "healthy/unhealthy") within a tight hackathon timeframe. Getting the full stack - auth through deployment - working end-to-end in a single sprint.
