TerrainFit

Terrain-Aware Posture Monitoring Backpack

Arduino Uno · Dual MPU6050 Gyroscopes · Embedded Sensors · C++

1st Place, College IoT Competition

Overview

A smart backpack that tells the difference between bad posture and just walking uphill.

Problem

Existing posture-monitoring wearables use a single accelerometer/gyroscope and flag any deviation from "upright" as bad posture. That means walking up a slope, climbing stairs, or navigating uneven terrain constantly triggers false positives — making the devices useless in real-world (non-flat, non-lab) conditions.

Architecture

Dual MPU6050 gyroscope setup — one reference sensor tracks terrain/body baseline angle, the second tracks spine/back angle relative to it — feeding into an Arduino Uno that computes relative deviation instead of absolute deviation.

Technical Deep-Dive

Team name: SpineSync, built by Advaith Kashyap and teammates. Dual-sensor differential approach: instead of asking "is the back at 90 degrees?", the system asks "is the back significantly deviated from the terrain-adjusted baseline?" This differential design is what eliminates the false-positive problem competitors have — the system distinguishes terrain-induced tilt from posture-induced tilt. Full embedded firmware written in C++ for Arduino Uno, real-time sensor fusion between the two MPU6050 units. Project taken through full lifecycle: ideation to hardware prototyping to firmware debugging to sensor calibration to academic paper writeup to professional documentation submission.

Challenges

Sensor drift and calibration between two gyroscopes reading simultaneously. Distinguishing "terrain tilt" from "posture slouch" in real time without a lag that would make the feedback useless. Hardware debugging under real constraints — this was physical hardware, not just code.

My Role

Core team member — hardware design, gyroscope calibration logic, embedded firmware, and academic paper writing.

Results
